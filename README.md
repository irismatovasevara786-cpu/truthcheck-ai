# TruthCheck AI

Қазақ тіліндегі медиасауаттылыққа арналған интерактивті веб-прототип. Оқушының прогресі браузердің `localStorage` санах ойд сақтана.

## Қосу

`index.html` файлын браузерде ашыңыз. Файл схемасымен жұмыс істейді, сервер не қосымша пакет қажет емес. Немесе жоба түбірінде Python бар болса:

```bash
python -m http.server 8000
```

Содан кейін `http://localhost:8000` мекенжайын ашыңыз.

## Мүмкіндіктер

- Ақпаратты мәтін, URL немесе сурет ретінде енгізіп, оқу мақсатындағы тексеру нұсқаулығын көру.
- Бес мысалы бар «Шынайы / Жалған / Күмәнді» тренажері, жауап түсіндірмесі және ұпай жүйесі.
- Оқушы кабинетінде браузерде сақталатын нәтиже, деңгей, жетістіктер және белсенділік диаграммасы.
- Үлгі көрсеткіштері белгіленген мұғалім кабинеті.
- Ұялы экрандарға бейімделген интерфейс және қазақша навигация.

## Шектеулер

Фактчекинг қызметі, AI модельдері, сервер және аккаунт жүйесі қосылмаған. Талдау бөлімі нәтижелерді әдейі демо нұсқаулық деп белгілейді; пайыз көрсеткіші үлгіленген UI элементі болып табылады және ешқандай сенімділік бағасын білдірмейді. AI контентті анықтау автоматты орындалмайды. Мұғалім бетінің сынып деректері демонстрациялық. Деректер құрылғылар арасында синхрондалмайды.

## Жоба құрылымы

- `index.html` — семантикалық бет мазмұны
- `styles.css` — визуалды стиль және responsive layout
- `app.js` — навигация, тренажер, талдау демосы, жергілікті прогресс
